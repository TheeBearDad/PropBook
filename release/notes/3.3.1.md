### New
- **Open PropBook when you sign in.** Tick it under **Accounts → Updates and startup**. On Windows it also shows up in Settings → Apps → Startup.
- **Pinning to the Windows taskbar works properly.** PropBook now has its own taskbar button with the PropBook icon. Pinning it pins PropBook instead of Edge or Chrome. If you pinned an earlier version, unpin that one and pin it again.

### Updating
If you have 3.3.0, click **Update now** on the bar at the top of PropBook. If you're on anything older, download this version below.

| Download | For |
|---|---|
| `PropBook-3.3.1-Windows.zip` | Windows 10/11 |
| `PropBook-3.3.1-macOS.zip` | macOS (Apple Silicon and Intel) |
