**Trade Journal is now PropBook.**

### New
- **Automatic updates.** PropBook checks GitHub for new versions and offers **Update now**. You can also turn on automatic installs under **Accounts → Updates**. Every update is checked against PropBook's signature before it's installed.
- **The extension updates itself.** PropBook keeps the extension in `Documents/PropBook/PropBook Sync`, and the extension reloads when that copy changes.
- **Accounts → Browser extension** shows the extension folder, an **Open extension folder** button, and whether the extension is connected and up to date.

### Moving from Trade Journal 3.2
- Your journal moves from `Documents/Trade Journal` to `Documents/PropBook` on its own the first time PropBook opens.
- Remove the old **Trade Journal Sync** extension. Then **Load unpacked** `Documents/PropBook/PropBook Sync` and paste your key again.
- 3.2 can't update itself, so download this version by hand once. Every version after it updates itself.
